# Nothing Official Store

Nothing Official Store is a responsive landing page for a technology store. It presents Nothing smartphones, audio products, and accessories in a clean product-focused layout with a mobile navigation menu and contact form.

## Live Preview

[View the live website](https://achekcss.github.io/frontend-to-do-app/)

## Technologies Used

- HTML5
- SCSS
- JavaScript
- Parcel
- GitHub Pages

## Getting Started

### Clone the repository

```bash
git clone https://github.com/AchekcSs/frontend-to-do-app.git
cd frontend-to-do-app
```

### Install dependencies

```bash
npm install
```

### Run the project locally

```bash
npm start
```

The development server will start and open the project in your browser.

## Features

- Responsive layout for desktop and mobile screens
- Mobile navigation menu with open and close controls
- Product recommendations and category sections
- Contact form with required fields
- Custom typography, icons, and product imagery
- SCSS-based styles organized into reusable sections and components

## Deployment

To create a production build and deploy it to GitHub Pages, run:

```bash
npm run deploy
```
